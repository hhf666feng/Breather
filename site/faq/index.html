常见问题

先了解，再歇会儿。

关于用眼时长、提醒、支持平台和产品边界的直接回答。

歇会儿是什么？

歇会儿 Breather 是桌面眼睛休息提醒工具，用电脑活动信号估算使用时长，并按设置提醒休息。它不是医疗设备，不诊断或治疗眼部疾病。

用眼时长等于真实注视屏幕的时间吗？

不等于。空闲检测只能提供电脑活动的近似信号，不能证明人在电脑前或正在看屏幕。静静阅读、播放视频、后台动画等场景可能与实际用眼不同；可选增强检测也不改变这一边界。

应用里的疲劳数值有医学意义吗？

没有。界面中的疲劳值是由使用与休息时长计算的提醒模型，不是对眼睛疲劳、视力或健康状态的测量，也没有经过临床验证。不要据此判断是否需要就医。

支持哪些设备？有 iPhone 应用吗？

macOS 1.6.2 支持 Apple Silicon 和 macOS 13+；Windows 1.6.0 为 x64 Electron 45.3.0 应用。没有 iPhone 应用、Intel Mac 发布包或 Windows ARM64 原生包。

免费吗？需要订阅或账号吗？

当前桌面版本免费下载，无订阅，不需要应用账号。免费使用不代表仓库附带开源许可证。

Mac 和 Windows 的记录会自动同步吗？

不会。设置与记录保存在本机，没有云端自动同步。可手动导出备份；不同平台与版本的备份格式不应假定可以互换，恢复前请保留原始数据。

需要哪些权限？会记录键盘内容吗？

macOS 可选的增强输入检测使用辅助功能权限，只取活动时间，不保留按键文字；可选屏幕活动检测需要屏幕录制权限，在内存中比较低分辨率灰度网格，不保存屏幕图像。Windows 版使用系统空闲时长，不提供相同的 macOS 增强检测。

为什么下载后会出现安全提示？

当前发布包未签名，macOS 也未公证，因此 Gatekeeper 或 SmartScreen 可能提示。请核实官方来源；不确定时不要绕过系统保护。

20-20-20 能保证缓解不适吗？

不能保证。它是一般性的屏幕休息建议，歇会儿没有证明任何医疗效果。持续眼痛、视物模糊或其他不适应咨询眼科或视光专业人士。
