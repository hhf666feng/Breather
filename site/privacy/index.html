隐私与数据

数据在本机，
边界说清楚。

应用数据、可选权限与网站托管分开说明。无需账号，也没有云端自动同步。

设置与记录保存在电脑上

桌面应用把设置、使用统计和休息记录保存到本机。Windows 版会在用户数据目录保存状态；macOS 版使用本地 Application Support 数据目录。卸载程序不一定删除这些数据，删除前请按需要导出备份。

不依赖账号或云端同步

当前桌面版本没有应用账号体系，不把统计记录自动同步到云端。CSV 导出和 JSON 备份由你手动操作，文件可能包含个人使用习惯；你选择的保存位置、云盘或分享渠道可能让文件离开本机。

macOS 可选权限

增强输入检测是可选的，使用辅助功能权限获取活动时间戳，不记录按键内容、指针位置或目标应用。屏幕活动检测也是可选的，需要屏幕录制权限：屏幕帧在本机内存中转为低分辨率灰度网格来比较变化，不保存截图或视频。屏幕权限仍属于敏感权限；不愿授权时可保持关闭，并可在系统设置中撤回。

Windows 的检测方式

Windows Electron 版使用系统空闲时间估算活动，不提供 macOS 的辅助功能增强输入或屏幕活动检测。这些信号不能确认真实视线、人是否在场或身体疲劳程度。

本网站与 GitHub 下载服务

本站是静态页面，不加载第三方字体、分析脚本或广告，也不设置应用自己的追踪系统。页面由 GitHub Pages 托管，下载通过 GitHub Releases 提供；GitHub 可能处理 IP 地址、请求和访问日志等服务数据，其处理方式受 GitHub 隐私政策约束。本地应用数据的说明不代表托管服务不会记录访问。

反馈时，请少分享一点数据

若通过公开仓库反馈问题，请不要上传个人备份、原始统计、敏感截图或系统凭据。问题描述与附件会受相应平台的公开可见性和隐私规则影响。
