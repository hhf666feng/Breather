Before you install

Current release files are not developer-signed. A system warning is not a safety verification. Obtain files only from the official GitHub Releases linked here and check the version. If you cannot verify the source or do not want unsigned software, do not bypass system protection.

Installation at a glance

  1. macOS: download and unzip the archive, then move Breather to Applications. If macOS blocks it, verify the source first and follow the relevant Privacy & Security prompt; do not disable Gatekeeper.
  2. Windows: run the installer, or keep the portable executable in a location you manage. Portable does not mean no local data is stored; see the privacy page.
  3. On first launch, choose a reminder rhythm. Enhanced input and screen activity detection on macOS are optional and permissions can be enabled as needed.

Versions and scope

The current macOS version is 1.6.2; the current Windows version is 1.6.0. There is no iPhone app or cloud autosync. Free distribution does not itself grant an open-source license; this page makes no open-source licensing claim.
