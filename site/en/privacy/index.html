Privacy & data

Local data.
Clear boundaries.

App data, optional automatic backups, permissions and hosting are separate. Local by default, without an app account.

Settings and records stay on your computer

The desktop app stores settings, use statistics and break records locally. Windows keeps state in a user-data directory; macOS uses a local Application Support directory. Uninstalling an app may not remove this data. Export a backup first if you want to keep it.

Optional automatic backups and cloud-drive boundaries

Data is local by default. Mac users can opt into an automatic backup folder; the app updates EyeWatch-backup.json about every 30 seconds and on key actions. If iCloud Drive is selected, the operating system may sync that file automatically. There is no built-in account, CloudKit cross-device merging or iPhone app. CSV and JSON backups can also be exported manually. Backups may reveal personal usage patterns; cloud-drive sync and sharing may take those files off-device. Choose destinations deliberately and protect your files.

Optional macOS permissions

Enhanced input detection is optional and uses Accessibility permission for activity timestamps, without recording key text, pointer positions or target apps. Screen activity detection is also optional and needs Screen Recording permission: screen frames are reduced to low-resolution grayscale grids in local memory to compare changes; screenshots and video are not saved. Screen permission is still sensitive. Leave it off if you prefer and revoke permissions in System Settings at any time.

Detection on Windows

The Windows Electron app estimates activity using system idle time. It does not provide the macOS Accessibility-based enhanced input or screen activity detection. These signals cannot confirm actual gaze, human presence or physical fatigue.

This website and GitHub downloads

This is a static website without remote fonts, analytics scripts, advertising or an app-operated tracking system. GitHub Pages hosts the site and GitHub Releases serves downloads. GitHub may process service data such as IP addresses, requests and access logs under its own privacy statement. The local-app data description does not mean the hosting service records no visits.

Share less when reporting an issue

When reporting an issue in the public repository, do not upload personal backups, raw records, sensitive screenshots or system credentials. Your report and attachments are subject to that platform’s visibility and privacy rules.
