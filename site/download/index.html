安装前，请知道

当前发布文件未进行开发者签名。系统警告不等于已经验证安全；只从本页链接的官方 GitHub Releases 获取文件，核对版本。若不确定来源或不愿运行未签名软件，请不要绕过系统保护。

如何安装

  1. macOS：下载 ZIP 并解压，将歇会儿移到「应用程序」。若系统阻止打开，请先核实来源，再按 macOS「隐私与安全性」中的提示操作；无需关闭 Gatekeeper。
  2. Windows：运行安装版，或把便携版放在自己管理的位置后运行。便携版不代表没有本地数据；请查看隐私说明。
  3. 首次打开后设置提醒节奏。macOS 的增强输入和屏幕活动检测是可选功能，权限按需开启。

版本与支持范围

macOS 当前版本为 1.6.2，Windows 当前版本为 1.6.0。默认在本机保存。Mac 用户可自愿选择自动备份文件夹，应用约每 30 秒及关键操作时更新 EyeWatch-backup.json；若选择 iCloud Drive，文件可由操作系统自动同步。没有内置账号、CloudKit 跨设备合并或 iPhone 应用。免费分发不等于授予开源许可证；本页面不作开源授权声明。
